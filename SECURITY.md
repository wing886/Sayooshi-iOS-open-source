# Security and issue reports

This is an experimental compatibility branch, not a security-supported product with a promised response time. There are no supported-version guarantees.

Do not put passwords, access tokens, pairing records, certificates, device identifiers, save files or copyrighted game resources in public Issues. For ordinary compatibility problems, provide a minimal reproduction description and redacted error text.

If GitHub private vulnerability reporting is enabled for this repository, use its Security tab for sensitive reports. Otherwise, ask the maintainer for a private reporting channel without disclosing exploit details or secrets publicly. No private reporting endpoint is implied by this document.

Run the source/index audit before commits and the history audit before changing repository visibility. A successful scan does not replace reviewing third-party licenses and newly added assets.
